# Математика и Алгоритмы CryptoSpread (v6)

Этот документ описывает "логику мозга" системы версии v6. Это необходимо для понимания того, как именно рассчитываются сигналы и почему они считаются качественными.

## 1. Расчет Спреда ( Spread Calculation )

Система использует две стадии проверки: **Raw (Грязный)** и **Net (Чистый)**.

### Грязный спред (Raw Spread):
`Spread_Raw = (Sell_Price - Buy_Price) / Buy_Price * 100`

### Чистый спред (Net Spread):
Это спред, из которого уже вычли торговые комиссии бирж.
`Net_Percent = Spread_Raw - (Fee_Buy + Fee_Sell) * 100`
*По умолчанию комиссии заложены как 0.06% (Taker) для каждой стороны, если не указано иное.*

---

## 2. Алгоритм VWAP и Проскальзывания (Slippage)

В v6 мы не просто смотрим на лучшую цену в стакане, мы "проедаем" стакан на глубину твоего рабочего объема.

### Формула VWAP (Volume Weighted Average Price):
Для заданного объема в долларах ($USD) система:
1. Берет уровни стакана по очереди.
2. Суммирует объем на каждом уровне, пока не наберется нужная сумма $USD.
3. Вычисляет среднюю цену исполнения.

**Пример:** Если ты хочешь купить на $10,000, а на первом уровне ($50,000) лежит всего $2,000 — система возьмет эти $2,000 по 50k, а остальные $8,000 по цене следующего уровня (например, 50,010).

### Проскальзывание (Slippage):
`Slippage = Net_Spread (Best) - Net_Spread (VWAP)`
Если проскальзывание слишком большое (стакан пустой), сигнал будет отфильтрован.

## 3. Оптимизация Tick Loop (100мс)

Система больше не считает всё подряд.

1. **Flag `is_dirty`**: Когда от биржи приходит новый стакан, символ помечается как "грязный".
2. **Цикл (Tick)**: Каждые 100мс Ядро Rust просыпается и смотрит список "грязных" символов.
3. **Расчет**: Спреды пересчитываются **только** для тех пар, где данные обновились. Если цена не менялась — ресурсы процессора не тратятся.

---

## 4. Фильтрация "Прострелов" (Lifetime Filter)

Чтобы ты не получал сигналы, которые исчезают через 0.1 секунды (на которых невозможно успеть заработать вручную):
- Система в Python Engine (Signal Engine) может отслеживать, как долго держится связка.
- Параметр `min_lifetime_seconds` (по умолчанию 3с) гарантирует, что сигнал "устоялся".

---

## 5. Анти-спам (Deduplication)

Для одного пользователя по одной и той же паре сигнал не может приходить чаще, чем раз в **60 секунд**. Это избавляет твой телефон от бесконечной вибрации по одной и той же ситуации.
