## ГЛОБАЛЬНОЕ ПРАВИЛО: НОРМАЛИЗАЦИЯ И МУЛЬТИПЛИКАТОРЫ (ОБЯЗАТЕЛЬНО К ИСПОЛНЕНИЮ)
- **[ПРИОРИТЕТ 1] ПРИ ДОБАВЛЕНИИ ИЛИ ПРОВЕРКЕ ЛЮБОЙ БИРЖИ СТРОГО ПРОВЕРЯТЬ НОРМАЛИЗАЦИЮ:**
  - При добавлении любых новых бирж (Gate.io, Bitget, BingX, KuCoin и т.д.) ОБЯЗАТЕЛЬНО реализовывать нормализацию префиксов контрактов (`1000`, `10000`, `1000000` -> `1000PEPE`, `1000BONK`, `1000000MOG`, `1000SATS`) к единому базовому тикеру (например, `PEPEUSDT`).
  - `multiplier` (`1000.0`, `1000000.0` или `1.0`) должен передаваться через `active_symbols_map` в Rust-коллекторы.
  - В Rust-коллекторах цена ордеров делится на `multiplier` (`p /= multiplier`), а количество умножается (`a *= multiplier`), чтобы USD-объемы сохранялись со 100% точностью, а цены за 1 монету сравнивались 1-к-1.

## Инструкция по запуску
1. **Инфраструктура:** `docker compose up -d` (Postgres & Redis).
2. **Запуск валидатора:** `uv run python tests/diag_math_validator.py` (запускает самотестирование и подключается к Redis).
3. **Запуск всей системы:** `uv run watchdog.py`.
4. **Строгое правило:** ВСЕГДА останавливать все фоновые процессы проекта (через Stop-Process или watchdog.py kill) перед компиляцией или редактированием файлов!
