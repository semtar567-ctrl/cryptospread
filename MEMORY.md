# Memory проекта CryptoSpread

## Текущий статус [19.05.2026]
Система успешно прошла сквозное тестирование. Связка Rust Core + Signal Engine + Telegram Bot полностью работоспособна.

### Что работает:
- **Rust Core:** WebSocket-коллекторы для Binance, Bybit и OKX. Исправлена нормализация символов (унифицированный формат `BTCUSDT`). Оптимизирована работа с Redis (кэширование настроек спреда на 5 секунд, переиспользование соединений).
- **Signal Engine:** Обработка сигналов из Redis, расчет VWAP (проскальзывания), учет комиссий, фильтрация по времени жизни (lifetime).
- **Volume Monitor:** Автоматическое обновление белого списка ликвидных монет (объем > $1 млн на 2+ биржах).
- **Telegram Bot:** Управление фильтрами, включение/выключение бирж и уведомлений. Добавлен OKX в меню выбора бирж.

### Известные ограничения:
- **Binance:** В текущей локации выдает ошибку 451 (REST API блокировка). WebSocket при этом может работать, но Volume Monitor не может получить список тикеров.
- **Спреды:** Мониторинг стабильно работает на паре Bybit <-> OKX.

---

## Инструкция по запуску (Checked)

Для работы системы должны быть запущены 4 окна:

1. **Telegram Bot:** `uv run python -m telegram_bot.main`
2. **Signal Engine:** `uv run python -m signal_engine.main`
3. **Volume Monitor:** `uv run python -m signal_engine.volume_monitor`
4. **Rust Core:** `cd rust_core; $env:RUST_LOG="info"; cargo run --release`
