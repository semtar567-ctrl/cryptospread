# Memory проекта CryptoSpread

## Текущая цель
- **Развитие и прокачка Web-терминала графиков спреда (`web/`):**
  - Доработка интерактивного веб-интерфейса и графиков TradingView (`web/static/index.html`, `app.js`, `web/server.py`).
  - Разработка живой таблицы активных спредов (Live Data-Grid) со звуковыми оповещениями (Audio Alerts) и индикаторами схождения/статистического спреда (Z-Score).

## Ближайшие шаги
1. **Этап 1.1:** Создание интерактивной панели / таблицы всех активных спредов реального времени (Live Spread Matrix / Grid) прямо в веб-интерфейсе.
2. **Этап 1.2:** Внедрение звуковых алертов при достижении целевых уровней спреда.
3. **Этап 1.3:** Оптимизация отображения свечей спреда и индикаторов TradingView на веб-терминале.
