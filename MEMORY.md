# Memory проекта CryptoSpread

## Статус [12.06.2026] - ПРОВЕДЕН АУДИТ И ПОВЫШЕНА НАДЕЖНОСТЬ ВЫЧИСЛЕНИЙ
- **Математический валидатор:** Разработан [tests/diag_math_validator.py](file:///C:/Users/semta/Projects/cryptospread/tests/diag_math_validator.py) с асинхронным сравнением в реальном времени расчетных данных (VWAP, Net Spread, Slippage) из Redis-стрима с расчетами на Python. Внедрен стартовый юнит-тест на эталонных значениях. В ходе аудита код был приведен в полное соответствие с mypy strict, добавлена защита от некорректных типов данных из JSON, внедрена проверка консистентности стаканов (Book Consistency Check) и обеспечен надежный Graceful Shutdown с закрытием Redis и отменой фоновых тасок при прерывании Ctrl+C.
- **Rust Core Unit-тесты:** В `rust_core/src/engine.rs` добавлен полноценный Unit-тест `test_calculate_vwap`, проверяющий расчеты средневзвешенных цен и проскальзываний на тех же эталонных значениях. Тест дополнен проверками всех пограничных случаев (нулевые/отрицательные объемы, пустые стаканы, превышение ликвидности).
- **Идентичность calculate_vwap:** Логика вычисления VWAP в Rust Core и Python-валидаторе приведена к 100% идентичности во всех пограничных условиях (включая защиту от деления на ноль при `price <= 0.0` и защиту от некорректных объемов `target_usd <= 0.0`).
- **Динамические комиссии:** Успешно внедрен расчет реальных комиссий с бирж через CCXT с умножением на 2.0 (для открытия + закрытия) во всей системе.
- **Схождение спредов:** Полностью реализована кнопка «🎯 Отслеживать схождение» с выбором готовых порогов (0.75%, 0.5%, 0.25%), ручным вводом через FSM и обходом фильтрации в Rust Core.

## Инструкция по запуску
1. **Инфраструктура:** `docker compose up -d` (Postgres & Redis).
2. **Запуск валидатора:** `uv run python tests/diag_math_validator.py` (запускает самотестирование и подключается к Redis).
3. **Запуск всей системы:** `uv run watchdog.py`.
4. **Строгое правило:** ВСЕГДА останавливать все фоновые процессы проекта (через Stop-Process или watchdog.py kill) перед компиляцией или редактированием файлов!
